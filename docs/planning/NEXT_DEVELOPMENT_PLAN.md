## 🔧 技術選型和架構決策

### 資料庫架構
```sql
-- 主要表結構設計
- players (玩家基礎資料)
- economy_accounts (經濟帳戶)
- islands (島嶼資料)  
- nations (國家資料)
- nation_members (國家成員)
- transactions (交易記錄)
```

### Discord整合架構
```
Discord Bot → Webhook → Zientis API → 模組系統
- 支援即時通知
- 雙向指令執行
- 數據同步
```

- **性能測試**: JMH + 自定義監控
