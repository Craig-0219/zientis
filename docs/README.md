# 📚 Zientis 專案文檔

## 文檔結構

### 🏗️ 架構文檔 (`architecture/`)
- **PROJECT_STRUCTURE.md** - 完整的專案結構說明，包含所有模組架構、依賴關係和開發狀態

### 📋 規劃文檔 (`planning/`)
- **ROADMAP.md** - 開發路線圖，展示已完成和進行中的階段
- **IMPLEMENTATION_PLAN.md** - 歷史實施計劃，記錄專案開發歷程
- **NEXT_DEVELOPMENT_PLAN.md** - 下一步開發計劃和技術債務分析
- **COMMIT_SUMMARY.md** - Discord Bot Token 混合架構整合完成記錄

### 🤖 Discord 整合文檔 (`discord/`)
- **DISCORD_BOT_INTEGRATION.md** - Discord Bot 整合架構設計
- **DISCORD_BOT_TOKEN_SETUP.md** - Discord Bot Token 設置指南
- **DISCORD_FEATURES_SUMMARY.md** - Discord 功能摘要

### 🧪 測試文檔 (`testing/`)
- **SERVER_TEST_SETUP.md** - 伺服器測試設置指南和測試計劃
- **TEST_DISCORD_INTEGRATION.md** - Discord 整合測試文檔

### 🚀 部署文檔 (`deployment/`)
- **DEPLOYMENT.md** - 專案部署指南

## 使用指南

1. **新開發者入門**: 先閱讀 `architecture/PROJECT_STRUCTURE.md` 了解整體架構
2. **了解專案進度**: 查看 `planning/ROADMAP.md` 了解當前開發狀態
3. **設置開發環境**: 參考 `testing/SERVER_TEST_SETUP.md` 建立測試環境
4. **Discord 整合**: 閱讀 `discord/` 目錄下的相關文檔
5. **部署到生產**: 參考 `deployment/DEPLOYMENT.md`

## 文檔維護

- 所有文檔使用 Markdown 格式
- 定期更新版本資訊和狀態
- 新功能完成後更新相應文檔
- 保持文檔與代碼同步
